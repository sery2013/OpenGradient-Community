# 🏆 Ritual Community Leaderboard

> Live analytics dashboard for Ritual community engagement.

[🌐 Live Site](https://github.com/sery2013/Ritual-Community/) 

---

## ✨ Features

### 📊 Leaderboard Table
- Sortable columns: **User**, **Posts**, **Likes**, **Retweets**, **Comments**, **Views**
- 🔍 Search by username
- 📄 Pagination for easy navigation

### 📈 Analytics Tab
- **Summary stats**: Total posts, users, views & averages
- **Top 10 Authors**: Most active contributors
- **Top 10 Posts**: Viral content by views/engagement
- **🔥 Activity Heatmap**: Best times to post (by day/hour)

### ⚙️ Filters
- Time range: `7d` | `14d` | `30d` | `All time`
- Hour filter: Analyze activity by specific hours

### 💾 Export
- Download data as **CSV** or **JSON**

---

## 🛠 Tech Stack

- **Frontend**: HTML5, CSS3, Vanilla JavaScript
- **Data**: JSON (auto-updated)
- **Automation**: Python + GitHub Actions
- **Hosting**: GitHub Pages

---

## 🔄 Auto-Updates

Data refreshes automatically via GitHub Actions. Last update timestamp shown in the header.
